# StudyMate AI — Student Personal Assistant

## Run
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
3. Type a question or use one of the suggested prompts.

No installation, server, account, or API key is required.

## Features
- Responsive chat interface
- Student-focused built-in responses
- Quick prompt buttons
- New conversation/reset
- Runs locally in the browser

## Technology
HTML, CSS, and vanilla JavaScript.

## Important limitation
This submission is a rule-based chatbot prototype. It does not connect to a live generative AI model or an external API. The response logic can be upgraded later by connecting a backend to an AI API.
